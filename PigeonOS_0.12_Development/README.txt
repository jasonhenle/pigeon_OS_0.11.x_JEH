PigeonOS 0.11 Development
========================

Active development lives here:

  Pigeon/                 Runnable app (Mac + Pi scripts + pigeonAssets)
  PigeonOS_0.12_GFX/      Design sources for this version (local duplicate of Pigeon_GFX; not in Pi tarball)
  testingEnvironments/    Standalone UI / widget previews
  README.md               Glossary (views, assets, shortcuts, modules)

Mac Desktop shortcuts (from installer/setup_desktop_launchers.sh):
  ~/Desktop/Pigeon (experiment).command  — this tree / branch PigeonOS_0.12
  ~/Desktop/Pigeon (0.11).command        — same as experiment (explicit 0.11 name)
  ~/Desktop/Pigeon (main).command        — ~/Desktop/Pigeon-main release worktree

Mac: open Pigeon/installer and run run_pigeon_0_12.command
Pi:  see Pigeon/installer/START-HERE.txt

Settings and credentials stay in ~/.pigeon_0_6 (shared with earlier installs).

The previous 0.10 development tree is archived at:
  ../Archive/PigeonOS_0.10_Development/

Do not link future builds to Archive/ or to the root Pigeon_GFX/ tree
(prefer PigeonOS_0.12_GFX/ for 0.11 design work).
